# CUADRA — Identidad Visual & Web Design System

**Versión:** 1.0  
**Marca:** CUADRA  
**Descriptor:** Desarrollo web a medida  
**Dirección visual:** geométrica · minimalista · editorial · tecnológica · arquitectónica

---

## 1. Esencia de marca

CUADRA es un estudio de desarrollo web enfocado en crear experiencias digitales a medida.

La identidad debe transmitir:

- Precisión
- Estructura
- Diseño
- Tecnología
- Profesionalismo
- Simplicidad
- Criterio
- Calidad

### Concepto

La marca nace de la combinación visual de los caracteres:

`¬` + `=`

El símbolo representa una idea de **estructura + equilibrio + resolución**.

No debe sentirse como un símbolo informático genérico. Debe funcionar como un elemento gráfico propio de CUADRA.

### Personalidad

CUADRA debe sentirse:

**Precisa. Sobria. Moderna. Inteligente. Arquitectónica.**

Evitar:

- Estética gamer
- Gradientes excesivos
- Neon/cyberpunk
- Interfaces genéricas de SaaS
- Exceso de efectos
- Diseño excesivamente corporativo
- Tendencias visuales pasajeras

# 2. Logo

## 2.1 Isotipo

El isotipo está construido a partir de una interpretación geométrica de:

`¬=`

Características:

- Geometría simple
- Trazos consistentes
- Alineación estricta
- Proporciones controladas
- Esquinas limpias
- Alta legibilidad a tamaños pequeños

El isotipo puede utilizarse de manera independiente.

## 2.2 Logotipo

Composición principal:

`[ISOTIPO]`

`CUADRA`

`DESARROLLO WEB A MEDIDA`

El descriptor debe utilizarse únicamente cuando el contexto necesite explicar la actividad de la empresa.

## 2.3 Variantes

Crear como mínimo:

1. Isotipo
2. Logo horizontal
3. Logo vertical
4. Logo monocromático claro
5. Logo monocromático oscuro
6. Logo reducido para favicon
7. Marca de agua
8. Avatar para redes sociales

## 2.4 Área de seguridad

Mantener alrededor del logo un espacio libre equivalente, como mínimo, a la altura del trazo principal del isotipo.

Nunca colocar elementos gráficos demasiado cerca.

## 2.5 Usos incorrectos

No:

- Deformar el logo
- Rotarlo
- Añadir sombras
- Añadir glow
- Utilizar múltiples colores dentro del isotipo
- Cambiar arbitrariamente sus proporciones
- Colocarlo sobre fondos de bajo contraste
- Utilizar contornos innecesarios

- `0.08em` a `0.16em`

Texto:
- Normal / ligeramente negativo según tamaño.

# 7. Sistema de layout

CUADRA utiliza una lógica de **grid editorial**.

## Desktop

- 12 columnas
- Gutter: 20–32px
- Márgenes laterales amplios
- Contenedor máximo: 1280–1440px

## Tablet

- 8 columnas
- Gutter: 16–24px

## Mobile

- 4 columnas
- Gutter: 16px
- Márgenes: 16–20px

## Principio

No llenar todo el espacio disponible.

El espacio vacío es parte de la identidad.

---

# 8. Sistema de espaciado

Utilizar una escala basada en múltiplos de 4/8:

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96 / 128`

Preferencias:

- Secciones: 96–160px desktop
- Secciones mobile: 64–96px
- Cards: 24–40px
- Elementos relacionados: 8–24px

---

# 9. Bordes y superficies

La interfaz debe utilizar bordes finos y discretos.

### Border

`1px solid rgba(242,241,237,0.12)`

Sobre fondos claros:

`1px solid rgba(15,17,17,0.12)`

### Border radius

Evitar interfaces excesivamente redondeadas.

Valores recomendados:

- 0px — elementos editoriales
- 2–4px — botones y controles
- 8px — cards
- 12px — imágenes / mockups

El lenguaje general debe ser **rectilíneo y arquitectónico**.

`180–250ms`

---

# 14. Microinteracciones

La interacción debe sentirse técnica y deliberada.

Utilizar:

- Transformaciones de 2–6px
- Cambios sutiles de opacity
- Underlines animados
- Expansión de bordes
- Reveals
- Parallax muy leve
- Hover sobre imágenes

No utilizar:

- Rebotes
- Efectos elásticos excesivos
- Glitch
- Partículas
- Animaciones constantes

### Motion

Easing recomendado:

`cubic-bezier(0.22, 1, 0.36, 1)`

Duraciones:

- Micro: 150–200ms
- Normal: 250–400ms
- Reveal: 500–800ms

Respetar `prefers-reduced-motion`.

# 15. Arquitectura visual de la web

## Header

Minimalista.

Elementos:

- Isotipo
- CUADRA
- Navegación
- CTA

Debe existir mucho espacio alrededor.

## Hero

Debe comunicar inmediatamente:

**Qué hacemos + para quién + por qué somos diferentes.**

Ejemplo:

> DISEÑAMOS EXPERIENCIAS DIGITALES A MEDIDA.

Subtexto:

> Sitios web rápidos, estratégicos y construidos alrededor de tu negocio.

CTA:

`VER PROYECTOS`

Secundario:

`HABLEMOS →`

## Proyectos

Mostrar los trabajos como piezas editoriales.

Cada proyecto debe incluir:

- Imagen
- Nombre
- Categoría
- Año
- Breve descripción
- Resultado / objetivo

## Servicios

No utilizar cards genéricas de SaaS.

Preferir una composición de lista / grid:

`01 — DISEÑO WEB`

`02 — DESARROLLO`

`03 — EXPERIENCIAS DIGITALES`

`04 — MANTENIMIENTO`

## Proceso

Presentarlo como sistema:

`01 DESCUBRIR`

`02 DEFINIR`

`03 DISEÑAR`

`04 DESARROLLAR`

`05 LANZAR`

## CTA final

Una sección visualmente fuerte.

Ejemplo:

> TENÉS UNA IDEA.  
> NOSOTROS LA CONSTRUIMOS.

## Footer

Minimalista.

Logo + navegación + contacto + redes + copyright.

# 16. Cards

Las cards no deben parecer componentes genéricos.

Características:

- Bordes finos
- Fondos sólidos
- Mucho espacio interno
- Tipografía clara
- Imágenes grandes
- Metadata pequeña
- Hover sutil

Una card debe parecer parte de una **composición editorial**, no una caja de dashboard.

# 20. Tono verbal

CUADRA habla de forma:

- Directa
- Clara
- Profesional
- Técnica cuando aporta valor
- Segura
- Sin exageraciones

Evitar:

- "Somos los mejores"
- "Soluciones innovadoras 360°"
- "Transformamos tu negocio con tecnología disruptiva"
- Lenguaje corporativo vacío

Preferir:

> Diseñamos y desarrollamos sitios web pensados para funcionar.

> Tu web debe verse bien. También debe convertir.

> Menos elementos. Mejor estructura.

---

# 21. Responsive / Mobile First

La identidad debe diseñarse primero para mobile.

Prioridades:

1. Legibilidad
2. Jerarquía
3. Velocidad
4. Navegación
5. Touch targets
6. Contenido
7. Animación

Los componentes deben adaptarse al espacio, no simplemente reducirse.

No utilizar layouts desktop comprimidos en mobile.

---

# 22. Accesibilidad

Objetivos:

- Contraste WCAG AA como mínimo
- Focus states visibles
- Navegación completa por teclado
- Targets táctiles de mínimo ~44px
- Alt text para imágenes relevantes
- HTML semántico
- Respeto de `prefers-reduced-motion`
- No depender únicamente del color para comunicar estados

---

# 23. Performance

CUADRA vende desarrollo web; la propia web debe demostrarlo.

Priorizar:

- Imágenes WebP/AVIF
- Lazy loading
- Fuentes optimizadas
- CSS eficiente
- JS mínimo
- Animaciones GPU-friendly
- Core Web Vitals
- Lighthouse alto

Evitar librerías innecesarias.

# 25. Regla de oro

**CUADRA no debe intentar demostrar que sabe hacer muchas cosas.**

Debe demostrar que sabe **hacerlas bien**.

La interfaz debe transmitir:

**PRECISIÓN / ESTRUCTURA / DISEÑO / CÓDIGO**

El resultado final debe sentirse como una combinación de:

**estudio de diseño + estudio de arquitectura + ingeniería digital.**

Nada debe estar colocado "porque queda lindo".

Cada elemento debe tener una razón.
